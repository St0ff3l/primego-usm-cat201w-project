# Agent 指南

本目录统一保存原先分散在 `backend/.claude`、`backend/.codex`、`admin-ui/.claude` 和 `admin-ui/.codex` 中的项目指南与技能。

- `agents/backend/`：RuoYi-Vue-Plus 后端任务指南，路径范围是 `backend/`。
- `agents/frontend/`：Plus Vue 管理端任务指南，路径范围是 `admin-ui/`。
- `skills/ruoyi-plus-ai-coding/`：后端和配套前端的 RuoYi-Vue-Plus 编码技能。
- `skills/frontend-crud-coding/`：Plus 管理端 CRUD 与页面编码技能。

技能内部的 `references/` 和 `agents/openai.yaml` 随技能目录保留；后端入口指南中的技能引用已改为本目录下的新路径。
